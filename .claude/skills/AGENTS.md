# Repository Skill Instructions

Skills describe reusable task procedures. Shared policies remain in
[AGENTS.md](../../AGENTS.md) and [TC conventions](../../tests/TC_CONVENTION.md).

- Keep frontmatter names stable and make activation conditions explicit.
- Use links to policy and node specifications rather than maintaining a separate rule set.
- Keep examples aligned with `libraries/` for Python and `resources/` for Robot files.
- Clearly label illustrative commands that require a local fake server or placeholder substitution.
