# Agent Workflow Documentation

`workflow.md` owns setup, validation selection, and reporting procedures.
`current-state.md` records the applied structure, checks, and remaining limitations.

- Keep repository policy in the root `AGENTS.md` and folder-specific rules in local guides.
- Record completed checks with their actual scope; distinguish structural validation from live PG verification.
- Keep status descriptions factual and update them when the layout or validation evidence changes.

## Workflow Ownership

Keep detailed task reading paths and validation availability in `workflow.md`.
The root instructions own mandatory checks and completion-report requirements;
local guides must not silently weaken them. Historical checks in `current-state.md`
must remain distinguishable from results obtained for a new change.
